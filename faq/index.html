FAQ

What is a managed GEO service?
Anscite's managed GEO service aims to make a brand appear in AI answers. It includes question mining, content creation with manual review, independent publishing, and AI engine reporting.
How does Anscite find the questions to target?
Anscite mines real questions and long-tail keywords from Baidu and Bing. These questions guide the content that is created for the brand.
Is the content reviewed before publishing?
Yes, Anscite generates content and reviews each piece manually. This manual review is part of the managed service.
How is the content published?
Anscite publishes content as independent sites with one-click publishing and independent domain binding. Each brand can have its own site.
Can Anscite manage multiple brands at once?
Yes, the system supports multiple brands in parallel, each with its own site and fact library.
How does Anscite report on AI engine visibility?
Anscite regularly probes multiple AI engines and produces reports. These reports can be viewed by users with the read-only role.
What user roles are available in the backend?
The self-service backend supports four roles: super admin, admin, member, and read-only. The read-only role can view all reports and content but is blocked from any write operations.
How are keys stored in the backend?
The backend stores keys only as ciphertext and does not display even the last few digits on list pages.
